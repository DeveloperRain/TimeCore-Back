Introducción
============

TIMECORE es una plataforma centralizada para administrar empleados,
sucursales, relojes checadores, asistencias, incidencias y prenómina.

El backend está desarrollado con FastAPI y utiliza PostgreSQL como
sistema gestor de base de datos. La comunicación con los relojes
biométricos se realiza mediante PyZK.

Objetivo
--------

Centralizar la información de los relojes checadores de las sucursales
y reducir el proceso manual de descarga, consulta y generación de
reportes de asistencia.

Funciones principales
---------------------

* Administración de sucursales.
* Administración de empleados.
* Registro y configuración de relojes checadores.
* Sincronización individual y general de dispositivos.
* Descarga y almacenamiento de asistencias.
* Generación de reportes.
* Gestión de incidencias.
* Generación de prenómina.
