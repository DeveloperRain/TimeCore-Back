Endpoints
=========

Documentación interactiva
-------------------------

FastAPI genera automáticamente la documentación OpenAPI:

* Swagger UI: ``/docs``
* ReDoc: ``/redoc``
* Esquema OpenAPI: ``/openapi.json``

Módulos principales
-------------------

Sucursales
~~~~~~~~~~

Permite consultar, crear y actualizar las sucursales registradas.

Empleados
~~~~~~~~~

Permite consultar empleados, actualizar su perfil y cambiar su estado.

Relojes checadores
~~~~~~~~~~~~~~~~~~

Permite registrar, configurar, consultar e inactivar dispositivos.

Asistencias
~~~~~~~~~~~

Permite consultar registros, aplicar filtros y generar reportes.

Prenómina e incidencias
~~~~~~~~~~~~~~~~~~~~~~~

Permite gestionar incidencias y generar información para prenómina.
